5. דרישות סף לחיבור
Prerequisites for Integration

להלן התנאים שחייבים להתקיים לפני תחילת עבודה. ודאו שכולם מתקיימים או ציינו אם נדרשת עזרה.

The following conditions must be met before we can begin. Confirm each item or flag if you need help.

  • חובה גישת API למערכת CRM
    לכל מערכת CRM שנבחרה, חייב להיות מפתח API פעיל. ב-ScallaCRM, נדרשת חבילת "מתקדם" (349 ש"ח/חודש) ומעלה. ב-ArBox, נדרשת חבילה עם גישת API. ב-HubSpot ו-Monday, נדרשת חבילה עם API tokens. Active API key required for each selected CRM. ScallaCRM: "Advanced" plan (349 NIS/mo) or higher. ArBox: plan with API access. HubSpot/Monday: plan with API tokens.
  • חובה הרשאות מנהל במערכת
    נדרשת גישת מנהל (Admin) למערכת ה-CRM כדי לאפשר את החיבור ולאשר הרשאות קריאת נתונים. Admin-level access to the CRM system is required to authorize the API connection and grant read permissions.
  • חובה נתונים קיימים במערכת
    המערכת חייבת להכיל לפחות 3 חודשי נתונים כדי לייצר דשבורד בעל ערך עם מגמות והשוואות. At least 3 months of historical data in the CRM is required to produce meaningful trends and comparisons.
  • חובה איש קשר טכני זמין
    צריך מישהו בצד הלקוח (בעל העסק או מנהל מערכת) שיכול לספק מפתחות API, לאשר הרשאות, ולענות על שאלות טכניות בזמן ההקמה. A technical contact (business owner or system admin) must be available to provide API keys, approve permissions, and answer setup questions.
  • מומלץ רשימת KPIs מתועדפת
    הגדירו מראש את 5-10 המדדים החשובים ביותר לעסק. זה מזרז את תהליך ההקמה ומבטיח שהדשבורד מתמקד במה שחשוב. Pre-prioritize your top 5-10 KPIs. This accelerates setup and ensures the dashboard focuses on what matters most.
  • מומלץ חומרי מיתוג (לוגו, צבעים)
    אם רוצים דשבורד ממותג - שלחו לוגו בפורמט PNG/SVG וקוד צבעים של המותג. For branded dashboards, provide your logo (PNG/SVG) and brand color codes.
